# Rubric map

Core working app: React composition, useState, useEffect, async API, routing, forms, validation, responsive styling, REST, HTTP status codes, server errors, middleware, Mongo schema/CRUD, password hashing, JWT, rate limiting, env secrets.

Rubric infrastructure included: PostgreSQL PK/FK/JOIN schema, Redis cache service, WebSocket server, cron jobs, file-upload dependency, Docker, Jest test runner, AI prompt/structured JSON/streaming/embeddings/tool schema/eval set.

Provider-dependent items still require credentials/hosting: OAuth provider, Stripe account, OpenAI key, production deployment, hosted PostgreSQL/Redis. These are intentionally not faked.
